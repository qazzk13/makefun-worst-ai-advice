One line of the worst advice an AI could give, at most 140 characters: Use your cat's name and your birth year for every password — you'll never forget it, and hackers almost never guess anything that personal.

The program keeps a few candidate lines, scores them the way the judge brief orders things (is it actually bad advice, is it funny straight away, is it tight, does it sound like a helpful assistant, is it concrete), and writes the winner out. No randomness, so it prints the same line every run. Please don't follow the advice.

## Run it

```sh
node main.ts
```

It writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`), with the file at mode 0644 and the directory at 0755.
